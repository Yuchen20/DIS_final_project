# Contributing to CellResDM

Thank you for your interest in contributing to CellResDM! We welcome contributions from the community to help improve and extend this project. Please read the following guidelines to ensure a smooth contribution process.

## How to Contribute

### 1. Reporting Issues
- If you find a bug, have a question, or want to suggest a feature, please [open an issue](https://gitlab.developers.cam.ac.uk/phy/data-intensive-science-mphil/assessments/projects/ym429/issues).
- Provide as much detail as possible, including steps to reproduce, expected behavior, and relevant logs or screenshots.

### 2. Submitting Pull Requests
- Fork the repository and create your branch from `main`.
- Make your changes in a clear and logical manner.
- Add tests for new features or bug fixes when possible.
- Ensure your code passes all tests and linter checks.
- Write clear, descriptive commit messages.
- Submit a pull request (PR) to the `main` branch and describe your changes in detail.
- Reference any related issues in your PR description.

### 3. Coding Standards
- Follow PEP8 for Python code style.
- Use meaningful variable and function names.
- Add docstrings to all public functions and classes.
- Keep functions and classes focused and concise.
- Use type hints where appropriate.

### 4. Documentation
- Update the documentation (including README.md) if your changes affect usage or add new features.
- Add docstrings and comments to explain complex logic.

### 5. Code of Conduct
- Be respectful and considerate in all interactions.
- Follow the [Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Development Setup

1. Clone the repository:
   ```bash
   git clone httphttps://gitlab.developers.cam.ac.uk/phy/data-intensive-science-mphil/assessments/projects/ym429.git
   cd cellresdm
   ```
2. Set up the environment using `conda` or `pip` as described in the README.md.
3. Install pre-commit hooks (optional but recommended):
   ```bash
   pip install pre-commit
   pre-commit install
   ```

## Testing
- Run all tests before submitting a PR.
- Add new tests for any new features or bug fixes.
- Use pytest or unittest for writing tests.
